# VSEPR

원자가 껍질 전자쌍 반발 이론(VSEPR)을 3D 그래픽으로 시각화하여, 분자의 구조와 결합각을 직관적으로 이해할 수 있도록 돕는 3D 시뮬레이터입니다.

고2 프로그래밍 수행평가로 만들었습니다.
파이썬이랑 C언어 둘 중 하나로만 자유롭게 코딩을 하는 과제였습니다.

이 당시 게임 개발에 관심이 있었어서 게임 개발이나 적어도 3D로 뭔가를 해보고 싶었습니다.

그래서 게임 엔진을 찾아보던 중 알게 된 것이,
1. Ursina Engine
2. Panda3D
3. Pygame
4. Kivy

입니다.

Panda3D는 초보자한테 친절하지 않고,
Pygame은 3D를 하기에 적절하지 않고,
Kivy는 게임엔진이 아니므로
Ursina를 선택했습니다.


이때 저는 VS Code를 굉장히 사랑했습니다. 그래서 당연히 이 시뮬레이터도 VS Code로 하려고 했습니다.
근데 하필 파이썬이 3.13 버전에서 3.14 버전으로 업데이트가 되던 때와 겹치는 바람에 VS Code에서 Ursina를 설치를 못 하는 상황이 생겨버렸습니다.
어쩌지 어쩌지 하다가 PyCharm을 써보았습니다. PyCharm에서는 3.14 버전 파이썬이 잘 되었고, Ursina엔진도 설치가 되었습니다. 그래서 이때 처음으로 PyCharm을 사용했습니다.


게임 개발을 할 때는 함수로 장면을 제어하는 것이 좋다고 어디서 주워들어서, 그걸 떠올리면서 분자 구조마다 함수로 나누어서 제어하도록 코드를 작성했습니다.

3D 환경에서 좌표 계산하는 것이 가장 어려웠습니다.
처음에는 계산도 하고 최대한 실제와 비슷하게 하기 위해 노력을 많이 했는데 이걸 계속 하니까 너무 지치더라고요. 그래서 후반부 쯤에는 눈으로 보기에 비슷해 보이는 정도로 타협을 봤었습니다.

공유 전자쌍이나 기타 등등 다른 것들은 Ursina엔진에 있는 기본 도형들을 써서 표현할 수 있었는데, 비공유 전자쌍은 비슷한 도형이 없어서 이때도 위기였습니다.
겁도 없이 모델링에도 손을 댔습니다. 처음으로 블렌더를 설치해서 해보니, 손도 못 댔습니다. 모델링을 직접 하면 반년은 더 걸릴 거 같아 무료 에셋 스토어를 찾아보았습니다.
비공유 전자쌍이 풍선 모양과 비슷하게 생겼길래, 풍선 모델을 찾아보았습니다. 무료 풍선 모델이 생각보다 찾기 힘들었는데 겨우 찾았습니다.
근데 풍선은 너무 풍선처럼 생겼길래 약간은 가공이 필요했습니다. 바로 전 설치했던 블렌더를 사용해서 풍선 모델을 약간 가공하여 비공유 전자쌍을 만들어서 Ursina 엔진으로 불러온 뒤 사용했습니다.

다 만들고 보니 생각보다 불친절하다고 느꼈습니다. 그래서 조금이나마 친절한 척이라도 해보자 싶어서 튜토리얼을 만들었습니다.
튜토리얼을 메인 코드에 만들어서 시뮬레이터를 시작하기 전에 띄울까, 다른 파일로 만들까 고민을 했는데 시뮬레이터 파일에 합쳐서 시작 전에 띄우게 하려면 코드를 뜯어고쳐야 할 거 같아서 그냥 새 파일을 만들어서 따로 만들었습니다.
